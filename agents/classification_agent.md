# Classification Agent (Phase 03)
## Purpose
Assigns qualified leads into one of three actionable commercial tiers:

### Priority 1: High Build-Readiness
- Criteria: No verified official website + Verified WhatsApp + Asset/Information rich.
- Action: Generate complete build-ready website architecture plan and package.

### Priority 2: Consultation & Asset Collection
- Criteria: No verified official website + WhatsApp + Limited public assets.
- Action: Generate consultation plan and owner question checklist.

### Priority 3: Modernization & Redesign
- Criteria: Existing website possesses evidence-backed weaknesses (poor mobile UX, outdated visual design, broken CTA).
- Action: Generate modernization and competitive rebuild plan.
